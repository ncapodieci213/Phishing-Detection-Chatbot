## 🛡️ Anti-Phishing Chatbot

A **lightweight AI-powered chatbot**, geared towards seniors, that helps users detect phishing or scam messages.  
You can paste suspicious emails, texts, or URLs into the chatbot, and it will:
- Evaluate how likely the text is a phishing attempt,
- Analyze patterns such as homoglyphs, blacklisted domains, and suspicious keywords,
- Generate a simple explanation via a large language model.

The system combines:
- ⚙️ **Machine Learning (ML)** for phishing classification  
- 🧠 **Large Language Model (LLM)** for natural, friendly explanations   
- 💬 **Gradio** for user interface  
- ⚡ Optional **GPU acceleration** for faster inference

## 🧰 Prerequisites

To get started with setting up this project locally, you'll need:
- **Python 3.10**
- **pip** (Python package manager)
- (Optional) **NVIDIA GPU + drivers** if using GPU acceleration

---

## ⚙️ Installation (Local)

1. **Clone the repository**
```bash
git clone https://github.com/ncapodieci213/Phishing-Detection-Chatbot.git
cd Phishing-Detection-Chatbot
```

2. **Create and activate a virtual environment**

```bash
python -m venv phishing
source phishing/bin/activate       # macOS/Linux
venv\Scripts\activate          # Windows
```

3. **Install dependencies**

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

---

## 🚀 Running the Chatbot (Local Gradio Interface)

Run the main app:

```bash
python main.py
```

This will generate a localhost link within your terminal:
👉 **[http://localhost:7860/](http://localhost:7860/)** 

---

## 💬 How to Use (Gradio Interface)

1. Open the Gradio app in your browser (`http://localhost:7860/`).
2. Paste any suspicious message, email, or SMS content in the text box.
3. Click **“Analyze”**.
4. View:

   * The **AI analysis**,
   * **Key indicators** the model found, and
   * A **natural-language explanation** generated by the LLM.

**Example:**

```
Input:
"Your PayPal account has been restricted. Click here to verify your details: http://páypal.com.secure-login.info"

Output:
**AI Analysis:**
**Risk Level:** High
**Key Findings:** 
- The message contains an explicit link to a phishing website.
- The link directs recipients to a malicious site with a suspicious domain (`http://paypa1.com/verify`).
- The urgency phrase "Act Now" and the use of "Limited Time" indicate the potential for immediate action.
- There are no genuine requests for sensitive information.
- The message appears to be impersonating a legitimate company.
- The overall tone and structure suggest it may be part of a larger phishing campaign targeting users who have already made a mistake.

---
📎 **URLs Detected:** 1 URL(s) found
  • http://paypa1.com/verify
    Domain: paypa1.com
```
